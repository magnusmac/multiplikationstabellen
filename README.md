# Gångertabellen

Ett fristående övningsverktyg för multiplikationstabellen 1–10. Allt ligger i `index.html` – ingen server, ingen installation, inga externa resurser. Fungerar offline i Chrome på Chromebook.

## Funktioner

- **Välj tabeller** (1–10, valfri kombination).
- **Räknesätt:** multiplikation, division eller båda.
- **Ordning:** blandad eller i ordning.
- **Längd:** 10 frågor, 20 frågor, hela tabellen eller 60 sekunder på tid.
- **Knappsats på skärmen** för pekskärm, eller tangentbord (siffror, Enter, Backsteg, Esc).
- **Direkt återkoppling:** vid fel visas rätt svar.
- **Resultat** med rätt, fel, tid och lista över felen – och knappen *Öva på felen*.
- **Tabellen:** interaktiv 10 × 10-tabell att titta i.

Ingen elevdata sparas. Bara de senast valda inställningarna sparas lokalt i webbläsaren.

## Använda

Öppna `index.html` i webbläsaren, eller lägg filen i Google Drive och dela den. Den kan också publiceras via GitHub Pages.
