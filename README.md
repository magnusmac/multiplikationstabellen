# Gångertabellen

Ett fristående övningsverktyg för multiplikationstabellen 1–10. Allt ligger i `index.html` – ingen server, ingen installation, inga externa resurser. Fungerar offline i Chrome på Chromebook.

Valda tabeller sparas och följer med mellan Öva, Spel och Kalkylblad.

## Delar

**Öva** – frågor med direkt återkoppling. Multiplikation, division eller båda; blandat eller i ordning; 10/20 frågor, hela tabellen eller 60 sekunder. Resultat med lista över fel och *Öva på felen*.

**Spel**
- *Bubblor* – tryck på rätt svar innan bubblan flyger iväg. Tre liv.
- *Para ihop* – memory med uträkning och svar.
- *Kapplöpning* – svara rätt för att springa ifrån snigeln, katten eller haren.
- *Bingo* – markera svaret på brickan, fyll en rad.
- *Sant eller falskt* – så många du hinner på en minut (tangenter S/F).

**Kalkylblad** – skapa utskrivbara blad: multiplikation, division, saknad faktor, blandat eller tom tabell. 20/40/60 uppgifter, facit på egen sida. Skriv ut eller välj ”Spara som PDF”.

**Tabellen** – interaktiv 10 × 10-tabell.

## Data

Ingen elevdata sparas. Bara inställningar och rekord (per dator) sparas lokalt i webbläsaren.

## Använda

Öppna `index.html` i webbläsaren, eller lägg filen i Google Drive och dela den. Den kan också publiceras via GitHub Pages.
